# Supermarket Sales EDA

An exploratory data analysis project that visualizes supermarket
sales data using Python.

## Project Overview

This project explores supermarket sales data to understand patterns
and distributions within the dataset.

The analysis focuses on exploratory visualization to become familiar
with the data and discover insights through different types of plots.

## Exploratory Data Analysis

The project includes:

- Data loading
- Data inspection
- Data preprocessing
- Date and time transformation
- Feature extraction
- Data aggregation
- Data visualization

## Visualization

Several visualization techniques are used:

### Line Plot

Used to analyze the total quantity of products sold across different
hours of the day.

### Histogram

Used to examine the distribution of unit prices.

### Box Plot

Used to analyze the distribution and spread of:

- Unit Price
- Tax 5%

## Features

Additional features are extracted from the transaction date and time:

- `hour` — hour of the transaction
- `weekday` — day of the week
- `month` — month of the transaction
